# Release Notes - v1.0

### Added
- **Email validation**: Now checks that emails contain both `@` and `.`.
- **Vowel counting**: `count_vowels` function now supports uppercase vowels (A, E, I, O, U).

### Fixed
- **Password validation**: Ensured passwords are at least 10 characters long.

### Security
- **Password validation**: Strengthened password check to enforce minimum length requirement.
